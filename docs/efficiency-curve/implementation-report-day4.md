## 交互流程

### 用户访问流程
1. 用户点击导航栏"效率曲线"
2. 进入效率曲线仪表盘
3. 查看工作日/周末画像和雷达图
4. 阅读效率洞察和建议
5. 点击"对比分析"（可选）
6. 查看详细的工作日vs周末对比

### 数据加载流程
```
用户访问页面
    ↓
useEffect触发
    ↓
并行请求API
    ├─ getProfile('workday')
    ├─ getProfile('weekend')
    └─ getInsights()
    ↓
数据加载完成
    ↓
渲染组件
    ├─ 画像卡片
    ├─ 雷达图
    └─ 洞察卡片
```

### 错误处理流程
```
API请求失败
    ↓
捕获错误
    ↓
显示错误信息
    ↓
提供"重试"按钮
    ↓
用户点击重试
    ↓
重新加载数据
```

## 响应式设计

### 桌面端 (≥768px)
- 画像卡片：2列布局
- 雷达图：全宽显示
- 洞察卡片：单列布局

### 移动端 (<768px)
- 画像卡片：单列堆叠
- 雷达图：自适应宽度
- 洞察卡片：单列布局

### 图表响应式
- 使用 `ResponsiveContainer` 组件
- 自动适应容器宽度
- 固定高度（400-500px）

## 性能优化

### 1. 数据加载优化
- 使用 `Promise.all` 并行请求
- 避免串行请求导致的延迟

### 2. 组件渲染优化
- 使用 `useState` 管理状态
- 避免不必要的重新渲染

### 3. 图表性能
- Recharts自动优化渲染
- 数据点数量控制（24个点）

## 技术栈总结

### 后端
- **语言**: Go 1.21+
- **框架**: Gin (HTTP路由)
- **数据库**: SQLite (WAL模式)
- **架构**: Repository模式，Handler-Service-Repository三层

### 前端
- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI库**: Ant Design + Tailwind CSS
- **图表库**: ECharts (ScreenTime), Recharts (Keyboard)
- **HTTP客户端**: Axios
- **日期处理**: dayjs

### 数据处理
- **Python**: 数据导入脚本、分析任务执行器
- **Docker**: 地理编码Worker容器化
- **Shapefile**: 离线地理编码（隐私保护）
